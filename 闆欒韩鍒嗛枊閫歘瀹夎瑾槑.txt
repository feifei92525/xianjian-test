弦間小日子｜學生帳號開通老師模式（修正版）

1. 備份網站及 Supabase 資料。
2. 在同一個 Supabase 專案的 SQL Editor 執行 supabase-dual-role.sql。
3. GitHub Pages 覆蓋 app.js 和 index.html（兩個檔案都要）。
4. Ctrl+Shift+R 重新整理，登入學生帳號。
5. 設定與資料備份 → 開通老師模式。
6. 左側選單切換學生／老師模式。老師端即使沒有學生也會顯示空白教學中心。

說明：這是開通身分，不會自動取得任何學生的資料；學生資料的可讀取權限仍由 music_pairs 配對和資料庫 RLS 決定。
本版尚未提供邀請碼配對；請勿將學生個人資料直接暴露給未配對帳號。
測試：JavaScript 靜態語法檢查；未在正式 Supabase 完成端到端測試。
