弦間小日子｜Bass 養成系統擴充測試版
=====================================
基於上一版「移除16堂課程版」擴充，不覆寫原本 Bass 練習、老師配對、聯絡簿、印章、挑戰、51 天進修資料表。

升級前
1. 備份 GitHub 儲存庫目前所有檔案，並從原網站匯出 Bass 練習及三技能進修紀錄。
2. 若你的正式網站並非上一版整合版，先比較檔案差異，不要直接覆蓋，以免覆蓋未納入的修改。
3. Supabase SQL Editor 執行 supabase-bass-growth.sql，新增 bass_growth_profiles 資料表與帳號專屬 RLS 政策。
4. 將 index.html、app.js、styles.css、study.js、planner-upgrade.js、bass-growth.js 上傳 GitHub 儲存庫根目錄。請保留原本的其他檔案。
5. GitHub Pages 更新後強制重新整理（Ctrl+Shift+R），用學生帳號檢查「技能圖鑑」「能力成長紀錄」「Bass 訓練工具」。再用老師帳號檢查原功能。

這一版的範圍
- 110 項核心技能 + 22 項曲風與專業擴充；技能熟練度 Lv.0–5、文字驗收證據、今日技能勾選。
- 智慧節拍器（每拍、2/4 拍、僅第 1 拍、每四小節靜音一小節）；標準四弦指板音名問答；音程聽力測驗。
- 16 步簡易 Groove 節奏器；四拍節奏符號視奏；技能專屬計時、BPM 記錄；瀏覽器錄音與本機 A/B 比較。
- 成就示範、成長紀錄、Bass 養成 JSON 匯出、手動 Supabase 上傳/下載。

重要限制
- 新模組的練習任務不會寫回原本 practice_days 的六大項目；兩邊紀錄並行保留。
- 錄音檔不存入 Supabase；請下載到電腦，A/B 比較也需要重新選檔。
- 雲端同步為手動整份覆蓋，沒有衝突合併。兩台裝置切換前請先匯出、上傳、下載確認。
- 計時器按「結束並記錄」才會存入資料；關閉分頁前請先儲存。
- 指板和聽力題目目前不自動統計正確率；技能熟練度不會自動升級。
- 視奏目前為節奏符號練習，尚非完整五線譜視奏；Groove 為簡易合成聲，不是完整鼓機。
- 未經正式網站實測；先用備份環境測試，再正式更新。
