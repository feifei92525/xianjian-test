弦間小日子｜自動雲端同步測試版

1. 先在目前網站匯出「51 天手帳」及「Bass 養成」JSON 備份；保留舊網站 ZIP。
2. Supabase → SQL Editor → 執行 supabase-auto-sync.sql（只需一次）。
3. 將本 ZIP 的網站檔案上傳 GitHub 儲存庫根目錄，覆蓋同名檔案。不要把 SQL 或說明文字當成網站頁面。
4. 在主要使用的裝置先登入原帳號，等待右上角顯示「☁️ 已同步」。
5. 再在第二台裝置登入同一帳號，等待同步；勾選一項任務，切回第一台，約 12 秒內或重新聚焦頁面會更新。

範圍：51 天進修紀錄、手帳日程/延期/日記/計時紀錄、Bass 技能/成就/BPM 等 JSON 資料。原有 Bass 每日練習與老師功能仍沿用既有 Supabase 資料表。
不包含：Bass 錄音音訊檔（仍須下載保存）；舊版「手動雲端同步」所存的快照不會自動匯入新同步表。若你的最新資料只在舊版手動雲端，請先在舊版下載到主要裝置，再升級。

資料安全：第一次登入會合併本機與雲端欄位；同一欄位若兩台同時編輯，最後送達伺服器的版本優先。請先備份再測試；不建議兩台同時編輯同一篇日記。
離線修改會保留在目前瀏覽器；若重新整理或關閉分頁，尚未成功送出的變更不保證都能恢復，請以「☁️ 已同步」作為確認。
同步需要保持網路連線和登入；資料不會公開給其他帳號。此版本尚未在你的 Supabase 正式環境完成端到端驗收。

更新後原手動上傳／下載按鈕仍保留作舊版相容，日常請不要使用它們，以免覆蓋自動同步資料。
