安裝：
1. 備份網站檔案，並匯出學習手帳 JSON。
2. 將本 ZIP 中 study-simple.js 與 styles.css 上傳至 GitHub 儲存庫，覆蓋同名檔案。其他檔案可以不覆蓋。
3. 重新整理網頁（Ctrl+Shift+R），進入「我的學習 > 學習成長」。
4. 若右上角仍顯示 Could not find table public.learning_sync_fields，請在 Supabase 正確專案的 SQL Editor 執行 ZIP 中 supabase-auto-sync.sql。此 SQL 會建立專用資料表與 RLS 政策；若已建立，不需重複執行。執行後重新整理網站並檢查帳號登入與同步狀態。
5. 請用電腦及手機登入同一帳號，先測試一個技能等級是否雙向同步，再正式使用。
